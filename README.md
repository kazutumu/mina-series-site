# ミナシリーズ サイト

GitHub Pagesでそのまま公開できる静的サイトです。ビルド手順はありません。

## 現在の掲載範囲

- 本編: 1〜100冊目
- ミナ文庫: 第1〜5巻
- 研究ノート: 1〜10冊目
- 森研究所マガジン: 1〜4冊目
- 外伝: 1〜10冊目

掲載範囲は `books/MINA_KDP_PUBLICATION_STATUS.md` の販売中・公開済み記録に合わせます。制作済みでも、KDP公開確認がない作品は追加しません。

森研究所マガジンVol.05『役割が生まれた森と、静かな制作室』とVol.06『一区切りの朝と、森に残った余白』は、それぞれ `books/mori-lab-magazine/vol05/`、`books/mori-lab-magazine/vol06/` に制作済みですが、どちらもKDP未提出・未販売・サイト未掲載です。販売確認前は掲載数を4冊から変更しません。

ミナ文庫シリーズ『ミナといくつもの道』は第1巻〜第6巻まで制作済みで、第6巻をもって成長編完結です。2026年8月27日にAmazonで販売中を確認した第1〜5巻を、旧本編の101冊目以降へ混ぜず、長編の独立した本棚として掲載しています。第6巻はKDP未提出・未販売・サイト未掲載です。

刊行状況と「迷ったら、この順番で」の各カードは、それぞれの本棚への入口です。ミナ文庫には専用の本棚があり、別枠の本棚では4つの切替ボタンで研究ノート・マガジン・外伝を絞り込めます。

## ファイル

- `index.html`: 一覧ページ本体
- `styles.css`: 画面デザイン
- `script.js`: 本編・ミナ文庫・関連本の一覧データと表示処理
- `*.jpg`: 表紙画像。GitHub Pagesの公開ルートに合わせて、画像は `index.html` と同じ階層に置きます。
- `sitemap.xml`: 検索エンジン向けのサイトマップ
- `robots.txt`: クロール許可とサイトマップ位置の指定

## 公開メモ

Amazonへのリンクは、基本的に作品名での検索リンクにしています。ASINが分かり、検索結果が自動補正される作品は、`script.js` の `asin` から商品ページへ直接リンクします。検索結果がずれる本は、`searchQuery` で検索語を調整することもできます。
